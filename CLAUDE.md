# For agents working in this repo

This repo is a published copy of its owner's private toolbox (`~/toolbox` on the owner's Mac). A republish step copies that toolbox over this repo, so this is not where the toolbox is developed.

- If you can push to nonstopmatt/agent-toolbox, you're working for its owner. Don't build features or change how the system works here, because anything changed only in this repo is overwritten by the next republish. Make the change in `~/toolbox`, then republish. If your environment can't reach `~/toolbox` (a cloud session, for example), say so plainly and leave a list of exact changes to port. Never tell the owner to pull this repo into `~/toolbox`: the two repos share no history.
- `README.md`, `CLAUDE.md`, `LICENSE`, `CONTRIBUTING.md`, `SECURITY.md`, `.github/` and the images in `docs/` exist only here, so edit those here.
- If you cloned this repo as your own toolbox, none of this applies. Your clone is your shelf, so follow `docs/SETUP.md`.
