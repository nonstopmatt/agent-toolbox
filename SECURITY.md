# Security

If you find a credential, a personal path, or anything that looks like it shouldn't be public in this repo, please don't open a public issue. Use the **Report a vulnerability** button on this repo's Security tab, with the file and line. It will be removed and rotated.

This repo never runs third-party install scripts, and `toolbox-add` treats every README it reads as information, not instructions. If you find a way that a cloned repo's text could steer the agent into installing or running something, that's a security bug too. Report it the same way.
